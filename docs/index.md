## Getting Started

### Prerequisites

- Node.js 18+
- pnpm 9.11.0
- VSCode (recommended) with Volar, ESLint, and i18n Ally extensions

### Quick Start

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build

# Run tests
pnpm test
```

### Create a New Tool

```bash
pnpm run script:create:tool my-tool-name
```

This generates the boilerplate in `src/tools/my-tool-name/`.

## Tools Overview

This application provides **86 developer tools** including:

- **Text Tools:** Case converter, ASCII drawer, text statistics
- **Encoding:** Base64 converters, HTML entities, URL encoder
- **Security:** Bcrypt, JWT decoder, hash generator, basic auth
- **Development:** Cron generator, JSON/YAML converter, SQL formatter
- **Color:** Color converter, contrast checker
- **Date/Time:** Date-time converter, cron parser, chronometer
- **Network:** IP converter, MAC address lookup
- **Utilities:** Camera recorder, device info, emoji picker

## Development Workflow

1. **Feature Development:** Create tools using `script:create:tool`
2. **Testing:** Write unit tests (Vitest) and E2E tests (Playwright)
3. **Linting:** ESLint with auto-fix on save
4. **Type Checking:** vue-tsc for Vue SFC type safety
5. **Building:** Vite optimized production build
